# 배포 전 법무·규제 검토 체크리스트 (마음 체크)

> 기준: 식약처 「의료기기와 개인용 건강관리(웰니스)제품 판단기준」(2026-02), 디지털의료제품법(2025-01-24 시행; 세부 조항별 시행일은 최신 법령 확인), 개인정보보호법.
> 목적: 진단·치료가 아닌 **선별 + 전문가 연결** 포지셔닝을 유지하기 위한 점검표.

> 실제 검토의 최소 증빙은 [법무·규제 검토 증빙 레지스트리](operations/legal-review-evidence.md)에 비식별 식별자로 기록합니다. 이 문서의 체크박스만 변경해서는 릴리스 준비도 게이트를 통과할 수 없습니다.

## 1. 규제 포지셔닝

- [x] 진단·치료·예방 효능을 표방하지 않는다.
- [x] 결과는 "선별 점수"로만 표현하고, 질병명·확률·등급 판정을 제공하지 않는다.
- [x] 결과·위기·README에 "진단 아님" 고지를 반복한다.
- [x] 식약처 권고 문구를 포함한다: "본 제품은 의료기기가 아니므로 질병 유무를 판단할 수 없으며, 질병 유무 판단을 위해서는 의사의 검진이 필요합니다."
- [ ] 마케팅·앱스토어 설명에서 "진단", "치료", "예방 효과" 표현을 사용하지 않는다.
- [ ] 의료기기 해당 여부가 불분명한 기능(개인화 위험 예측, 자동 진단 등)은 추가하지 않는다.

## 2. 사용 목적·위해도 판단 (식약처 지침 요약)

- 의료기기 여부는 **사용목적**과 **위해도**로 판단한다.
- 질병의 진단·치료·예후 관찰, 치료 반응 예측, 치료 효과·부작용 모니터링 목적이면 디지털의료기기 해당 가능.
- 일상적 건강관리(웰니스) 목적이고 위해도가 낮으면 원칙적으로 의료기기로 보지 않는다.
- 본 앱은 검증된 선별 도구를 사용하되 **진단을 제공하지 않고 전문가 연결을 안내**하는 선별·웰니스 포지셔닝을 유지한다.
- 필요 시 식약처 「의료기기 해당 여부 검토 신청」을 통해 공식 확인을 받는다.

- 상업화·유료화·의료기관 연계 시에는 별도 법무 검토와 식약처 확인이 필요하다.

## 8. 상업화·의료기관 연계 게이트 (필수)

아래 중 하나라도 해당하면 **구현을 배포하지 말고** 법무·규제 검토를 먼저 완료한다.

| 트리거 | 필요한 조치 |
|---|---|
| 유료화·구독·광고 도입 | 법무 검토, 약관·개인정보처리방침, 광고 심의 |
| 의료기관·상담기관과 연계 | 의료법·개인정보보호법 검토, 데이터 처리 계약(DPA) |
| 진단·치료·예후·처방 관련 기능 추가 | 식약처 **의료기기 해당 여부 검토 신청** 및 허가·인증 절차 |
| 개인 맞춤 위험 예측·ML 점수 | 디지털의료기기 해당 가능성 검토, 임상 근거·성능 평가 |

| 청소년 대상 확대·보호자 연계 | 법정대리인 동의, 아동·청소년 보호 정책, 1388 연계 |

### 식약처 검토 절차 (요약)

1. 제품의 **사용목적**을 문장으로 명확히 한다(진단인지, 선별·연결인지).
2. 「의료기기 해당 여부 검토 신청」을 통해 공식 판단을 요청한다(사용목적·구조·성능·사용방법 자료).
3. 의료기기 해당 시: 품목 분류·등급, 허가·인증·신고, 소프트웨어 품질관리 기준을 검토한다.
4. 비해당 판단 시에도 “의료기기 아님” 고지와 진단·치료 표현 금지를 유지한다.
