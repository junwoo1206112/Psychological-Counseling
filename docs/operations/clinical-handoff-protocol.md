# 임상 후속연결 운영 프로토콜 템플릿

> 상태: **템플릿 — 실제 운영 증빙 전 미완료**  
> 적용: ASQ 양성 또는 앱의 위기 신호 뒤에 의료·상담기관이 실제 후속연결을 제공하려는 경우  
> 비적용: 현재 공개 앱의 자가 선별·109/119/112/1577-0199/1388 안내 자체

> 실제 운영의 최소 증빙은 [임상 후속연결 운영 증빙 레지스트리](clinical-handoff-evidence.md)에 비식별 식별자로 기록합니다. 이 문서의 체크박스만 변경해서는 릴리스 준비도 게이트를 통과할 수 없습니다.

## 1. 범위와 한계

- 이 앱은 자가 선별과 위기 자원 안내를 제공할 뿐, BSSA(Brief Suicide Safety Assessment), 진단, 치료, 예약, 자동 구조 요청을 수행하지 않습니다.
- ASQ 양성은 훈련된 임상가의 후속 평가 필요성을 알리는 신호입니다. NIMH의 ASQ 자료는 양성 선별 뒤 훈련된 임상가가 BSSA를 수행해 추가 평가 필요성을 판단하도록 안내합니다.
- 109의 지역 센터 연계는 본인 동의를 전제로 합니다. 앱은 사용자 동의 없이 응답·연락처·위험 정보를 기관에 전송하지 않습니다.
- 본 문서는 의료기관·상담기관의 자체 임상 지침, 법률 자문, 응급 대응 정책을 대체하지 않습니다.

## 2. 운영 시작 전 필수 결정

| 항목 | 정해야 할 내용 | 현재 상태 |
|---|---|---|
| 책임 | 임상 운영 책임 역할, 대체 책임 역할, 연락 가능한 운영 시간 | 미지정 |
| 대상 | 성인/청소년 범위, 제공 지역, 제외 기준 | 미지정 |
| 후속평가 | BSSA 담당 직군·훈련·감독, 급성/비급성 양성의 분기 | 미지정 |
| 시간 기준 | 응답/연락/후속평가 목표 시간, 야간·휴일 대체 경로 | 미지정 |
| 데이터 | 명시적 동의, 최소 데이터, 암호화·보관·파기·철회 | 미지정 |
| 실패 대응 | 연락 불가, 연결 실패, 담당자 부재, 사고 보고·재검토 | 미지정 |

## 3. 사용자 경로 원칙

1. **급성 신호**: 앱은 결과를 건너뛰고 위기 안내를 먼저 표시합니다. 사용자가 즉시 119·112·109 또는 가까운 응급 도움을 이용하도록 안내합니다. 앱은 사용자를 추적하거나 자동으로 외부에 알리지 않습니다.
2. **ASQ 비급성 양성**: 앱은 ‘추가 전문가 평가 필요’로 안내합니다. 실제 기관 연계가 도입된 경우에만, 훈련된 임상가의 BSSA와 기관 정책에 따른 후속평가로 연결합니다.
3. **동의**: 기관에 정보를 전달하기 전 전달 범위·목적·수신자·거부/철회 방법을 명확히 설명하고 별도 동의를 받습니다. 동의하지 않아도 앱의 위기 자원 안내는 계속 제공합니다.
4. **연결 실패**: 기관 연결이 되지 않거나 운영 시간이 아니면 109·119·112·1577-0199·1388 및 신뢰할 수 있는 사람에게 도움을 요청하도록 안내합니다.

## 4. 증빙 체크리스트

아래 항목은 실제 운영 책임자와 임상·법무 검토를 거친 뒤에만 체크합니다. 이 저장소에는 이름, 연락처, 환자 정보, 상담 기록을 넣지 않습니다. 상세 증빙은 접근 통제된 기관 기록으로 보관하고, 이 문서에는 승인 여부와 내부 문서 식별자만 남깁니다.

- [ ] 임상 운영 책임 역할이 지정되었고, 부재 시 대체 책임 역할이 지정되었다.
- [ ] ASQ 양성 후 BSSA를 수행할 훈련된 임상가와 가용시간이 확인되었다.
- [ ] 급성·비급성 양성 각각의 후속 시간 기준과 장애 시 대체 경로가 승인되었다.
- [ ] 데이터 전달은 명시적 동의 후에만 수행하며, 동의 거부·철회 절차가 확인되었다.
- [ ] 사고·연결 실패·운영 중단 시 사용자 안내와 내부 보고 절차가 확인되었다.

## 5. 검토 근거

- [NIMH ASQ Toolkit](https://www.nimh.nih.gov/research/research-conducted-at-nimh/asq-toolkit-materials): ASQ 양성 뒤 훈련된 임상가의 BSSA 필요성을 안내합니다.
- [NIMH ASQ Information Sheet](https://www.nimh.nih.gov/research/research-conducted-at-nimh/asq-toolkit-materials/asq-tool/asq-information-sheet): 급성·비급성 양성의 후속평가 원칙을 안내합니다.
- [보건복지상담센터 109 FAQ](https://www.129.go.kr/faq/faq06.do?searchConsultingKeyword=F01): 고위험 판단 시 본인 동의 후 지역 센터 등으로 연계될 수 있음을 안내합니다.
