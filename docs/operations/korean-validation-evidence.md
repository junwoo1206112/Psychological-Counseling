# 한국어 타당화 증빙 레지스트리

> 상태: **연구·승인 미완료**. 이 문서는 PHQ-9, PHQ-A, GAD-7 및 비채점 기능손상 문항의 한국어판 타당화 과정을 추적하는 템플릿입니다. ASQ는 NIMH 공식 한국어판을 유지하며 이 레지스트리의 번역 승인 대상으로 바꾸지 않습니다.
> 연구 참여자 정보, 원자료, 설문 응답, 연락처, 면담 기록은 이 저장소에 넣지 않습니다. 외부의 승인된 연구 저장소·기관 기록을 가리키는 비식별 증빙 식별자만 기록합니다.

## 앱 상태와 범위

- 현재 `translationStatus`는 `unofficial`입니다. 실제 타당화·독립 임상 승인·문항 해시 검토·코드 변경 검토가 모두 끝나기 전에는 `validated-ko`로 바꾸지 않습니다.
- 타당화 증빙은 선별 도구의 한국어판 이해·측정 특성을 확인하기 위한 것이며, 이 앱의 진단·치료·자살 위험 예측 또는 BSSA 수행을 허용하지 않습니다.
- ASQ 양성·급성 신호의 위기 우선 라우팅과 전문가 후속평가 필요성은 연구 단계와 무관하게 유지합니다.

## 문항 지문(fingerprint)

실제 연구를 시작할 때 아래 해시를 연구 프로토콜·증빙 범위와 대조합니다. 문항이 바뀌면 해시가 바뀌므로, 새 해시에 맞는 연구·승인 없이 과거 기록을 재사용할 수 없습니다.

- PHQ-9 한국어 해시: `기록 전`
- PHQ-A 한국어 해시: `기록 전`
- GAD-7 한국어 해시: `기록 전`
- 기능손상 한국어 해시: `기록 전`

## 기록 규칙

- ID: `KVAL-YYYYMMDD-설명자` 형식이며 날짜는 기록일과 일치해야 합니다.
- 범위: 모든 기록은 `PHQ-9,PHQ-A,GAD-7,IMPAIRMENT`를 정확히 적습니다. 일부 도구만 연구했다면 나머지 범위를 `PASS`로 기록하지 않고 별도 연구를 진행합니다.
- 결과: `PASS` 또는 `FAIL`만 사용합니다. 가장 최근 유효 기록이 `PASS`여야 하며, 같은 날짜의 충돌은 `FAIL`이 우선합니다. 존재하지 않거나 미래인 날짜는 유효하지 않습니다.
- 증빙 식별자: 비식별 연구 프로토콜, IRB/면제 번호, 버전 관리된 보고서, 분석 재현 저장소 또는 독립 검토 기록의 식별자만 기록합니다. 원자료·참여자 정보·개인명은 적지 않습니다.

| 기록 ID | 기록일 | 단계 | 범위 | 결과 | 외부 증빙 식별자 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 필수 단계

| 코드 | 필요한 외부 증빙 |
|---|---|
| `GOVERNANCE` | IRB 심의/면제 판단, 동의·철회, 민감정보 보호·위기 대응 계획 |
| `TRANSLATION` | 독립 순번역·역번역·전문가 위원회 대조표 |
| `COGNITIVE` | 인지면담 결과 요약과 문항별 수정 판단 |
| `PILOT` | 파일럿의 이해도·응답 분포·수정 결정 보고 |
| `MAIN-STUDY` | 사전 정의 표본·기준 표준·모집 한계가 명시된 본조사 보고 |
| `ANALYSIS` | 신뢰도·구조/측정불변성·준거 타당도·절단점 분석 및 재현 정보 |
| `CLINICAL-APPROVAL` | 독립 임상·심리측정 검토자의 적용 범위·한계 승인 |
| `APP-RELEASE` | 현 문항 해시, 결과 문구·밴드·라우팅 회귀 검토와 배포 책임자 승인 |

## 배포 전 확인

- [ ] 모든 필수 단계의 최신 유효 기록이 `PASS`이다.
- [ ] 기록의 범위와 네 개 한국어 문항 지문 해시가 현재 코드와 일치한다.
- [ ] `translationStatus`·버전·해시 변경은 독립 임상·법무 검토와 코드 회귀 검토 뒤에만 수행했다.
- [ ] 연구 참여자 원자료와 개인식별정보가 이 저장소에 없다.

`npm.cmd run validation:evidence:check`은 기록 형식·단계·최신 결과·문항 지문 해시만 검사합니다. 연구의 과학적 적절성, IRB의 효력, 임상·법무 승인 사실을 자동으로 증명하지 않습니다.
