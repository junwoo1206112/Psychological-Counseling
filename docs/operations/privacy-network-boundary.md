# 개인정보·네트워크 경계

> 목적: 이 앱은 민감한 선별 응답을 서버·분석·광고·크래시 리포팅으로 자동 전송하지 않는다는 설계를 코드 수준에서 반복 확인합니다.

| 범위 | 정책 |
|---|---|
| `app/`, `components/`, `lib/`, `data/` | `fetch`, XHR, WebSocket, EventSource, `sendBeacon`, 분석/크래시 SDK, 콘솔 로그 금지 |
| 사용자 명시 동작 | `tel:` 전화와 공식 위기 자원/센터 링크 열기는 허용. 앱이 응답·연락처·점수를 전달하지 않음 |
| `public/sw.js` | 동일 출처의 정적 앱 자산과 오프라인 위기 안내 캐시만 허용. 외부 URL·백그라운드 동기화·응답 전송 금지 |
| 기기 내 저장 | 사용자가 선택한 점수·위험 수준·안전 계획 메모만 브라우저 저장소에 보관. 서버 전송 없음 |

감사 규칙을 정의하는 `lib/privacy-audit.js` 자체는 금지 API의 이름을 패턴으로 포함하므로, 오탐 방지를 위해 검사 대상에서 명시적으로 제외합니다. 이 파일은 앱 실행 경로가 아니라 정적 검사 규칙입니다.

## 검사 한계

- `npm.cmd run privacy:check`은 정적 패턴 검사입니다. 브라우저, 배포 인프라, 외부 링크 대상, 의존성 공급망 전체를 보안 감사하거나 법적 적합성을 보증하지 않습니다.
- 기능을 추가해 서버, 분석 SDK, 계정, 기관 연계 또는 외부 API를 도입하려면 법무·프라이버시·임상 검토와 별도 설계가 필요합니다.
- 서비스 워커의 `fetch`는 정적 자산/오프라인 지원을 위한 브라우저 동작이며, 앱 응답을 수집하거나 전송하는 기능이 아닙니다.
