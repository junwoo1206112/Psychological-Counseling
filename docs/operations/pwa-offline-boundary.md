# PWA 오프라인 정적 자산 경계

서비스 워커는 설치할 때 오프라인 위기 안내, 매니페스트, PWA 아이콘, `bootstrap.js`, `global.css`를 같은 출처 캐시에 넣는다. 이 목록은 위기 상황에서 필요한 최소 안내·기본 접근성·설치 식별 자산만 포함한다.

캐시는 GET 요청과 동일 출처 정적 자산으로 제한한다. 설문 응답, 결과 세션, 안전 계획 메모, `localStorage`/`sessionStorage` 값, 외부 URL, 분석·전송·백그라운드 동기화는 서비스 워커 캐시에 포함하지 않는다. 오프라인 탐색 요청은 `offline.html`의 위기 안내로만 대체된다.

`npm.cmd run pwa:check`은 필수 사전 캐시 자산, 캐시 버전, 동일 출처·GET 경계와 전송/저장소 API 부재를 검사한다. 실제 설치 후 오프라인 동작, 전화 앱 전환, 브라우저별 캐시 정책은 수동 실기기 증빙으로 확인해야 한다.
