## 2. 충돌 지점과 해소

### 2.1 화면 순서: 우울 먼저 vs 안전 먼저
- A: PHQ-9 먼저, ASQ 나중. B: 현재 자살사고·계획·수단을 **설문 초반**에.
- **해소**: 시작 직후 **짧은 현재 안전 확인(4문항)** → 급성 위험이면 즉시 crisis 종료. 급성이 아니면 PHQ-9/PHQ-A → 기능손상(비채점) → GAD-7 → ASQ(전원). 이렇게 하면 B의 "안전 우선"과 A의 "검증된 순서"를 모두 만족한다.
- 현재 안전 확인 문항: ① 지금 죽고 싶은 생각, ② 계획, ③ 쓸 수 있는 물건/혼자 안전 유지 어려움, ④ 과거 자해·자살 시도. "잘 모르겠어요"는 양성으로 처리.

### 2.2 Stepped(PHQ-2 게이트) vs Full PHQ-9
- C: PHQ-2 → PHQ-9로 문항 수를 줄인다. A: 9문항뿐이므로 게이트하지 말 것(민감도 약 4% 손실).
- **해소**: **PHQ-9 전원 시행**. 대신 GAD-7은 PHQ-9 이후, ASQ는 위험 확인 후 배치해 총 20~24문항(약 4분)으로 유지. "빠른 확인"이 필요한 경우를 위해 PHQ-2/GAD-2는 향후 옵션으로만 남긴다.

### 2.3 한국어판 PHQ-9/GAD-7 라이선스
- A: 검증된 한국어판을 사용하라. C: 한국어판은 별도 저작물이고 포털은 2차 배포를 금지한다. 영문 원문만 퍼블릭 도메인이다.
- **해소**: PHQ-9/GAD-7은 public domain이며 PHQ Screeners 약관상 번역·복제·배포가 허용된다. 이 저장소는 **한국어 이해용 번역과 영문 원문을 함께 제공**하고, 채점은 영문 원문 기준임을 화면·결과·README에 명시한다. 국가정신건강정보포털/블루터치/트로스트 문구는 **복사하지 않는다**. 임상·상업 사용 전에는 한국어판 자체 타당화 또는 공식 타당화판 검토가 필요하다.

### 2.4 C-SSRS vs ASQ
- A: C-SSRS는 예측력이 약하고 출처 간 triage 불일치. C: eC-SSRS는 별도 라이선스. B: ASQ가 가장 실용적.
- **해소**: **ASQ만 사용**, C-SSRS는 로드맵에서 제외.

### 2.5 안전계획 범위
- B: 6단계 안전계획 + follow-up. A/C: 앱은 작성 보조까지만, 완성은 임상가와.
- **해소**: 결과 화면에 **6단계 안내 + 로컬 메모(선택)** 를 제공하되, "전문가와 함께 점검" 문구를 고정. 자동 공유·자동 통보 없음.

### 2.6 연령
- A: 성인 척도와 청소년 척도가 다르다. B: 만 14세 미만 보호자 동의, 1388 안내. C: 연령 게이트.
- **해소**: 이번 구현은 **성인(18+) 기본**으로 하고, 시작 화면에 "만 18세 미만은 1388 안내"를 넣는다. 청소년 전용 척도는 후속 범위.

## 3. 최종 권장안 (이번 구현 범위)

### 3.1 사용자 흐름
```
인트로(동의·안내·상시 위기 배너)
  → 현재 안전 확인 4문항
      ├ 급성 위험 → /crisis (설문 즉시 종료)
      └ 그 외 → PHQ-9 9문항 (청소년은 PHQ-A 9문항)
                → 기능손상 1문항(비채점)
                → GAD-7 7문항
                → ASQ 4문항 (+ Q5)
                    ├ Q5 양성 → /crisis
                    └ 그 외 → /result
  → 결과: 우울 점수/밴드 + 불안 점수/밴드 + 자살 선별 상태
          + 기능손상 안내 + 위험 등급별 다음 행동 + 안전계획 + 위기 자원
```

### 3.2 결과 표시 원칙
- **복합 점수·퍼센트 링 없음.** PHQ-9 12/27, GAD-7 9/21처럼 **척도별 점수와 밴드**만.
- **"DSM-5 충족 가능성" 삭제.** "선별 결과이며 진단이 아님" 고정.
- 자살 선별은 **급성 / 비급성 양성 / 음성** 3상태. "위험 점수" 없음.
- 위험 등급: `acute`(즉시 crisis), `urgent`(당일~72시간), `routine`(2주 내), `monitor`(2~4주), `low`.
- 모든 결과에 109/119/112 + 정신건강복지센터/1577-0199/1388 안내.

### 3.3 위험 라우팅 (구현 규칙)
```
acute:
  safety.currentIdeation == yes
  OR safety.plan == yes
  OR safety.meansOrUnsafe == yes
  OR ASQ.q5 == yes
urgent:
  ASQ.anyPositive == true (q5 아님)
  OR PHQ9.item9 >= 2
  OR PHQ9.total >= 20
  OR GAD7.total >= 15
  OR safety.pastAttempt == yes
  OR impairment in (very, extreme)
routine:
  PHQ9.total 10–19 OR GAD7.total 10–14
monitor:
  PHQ9.total 5–9 OR GAD7.total 5–9
low:
  PHQ9.total 0–4 AND GAD7.total 0–4 AND ASQ negative
```

### 3.4 데이터·프라이버시
- 서버 없음, analytics 없음, 응답 콘솔 로그 없음.
- 저장은 opt-in(이번 구현은 세션 내 메모리만; 저장 버튼은 추후).
- ASQ 무응답은 양성으로 처리.
- 결과 공유 시 민감정보 제거(이번 구현은 공유 기능 없음).

### 3.5 정리 대상
- 삭제: `data/questionnaire.js`(50문항), `bin/generate-questions.js`, `bin/simulate-questions.js`, `bin/depression-assessment-v3.js`, `bin/validate-questionnaire.js`, `templates/questionnaire-template.js`.
- 교체: `bin/validate-instruments.js`(스키마·밴드·라우팅 검증), `tests/*`(node --test).
- 수정: `SKILL.md`(AI 문항 생성 → 검증된 선별·위기 라우팅 스킬로), `AGENTS.md`, `README.md`, `app/*`, `package.json`(test/validate 스크립트).

## 4. 수용 기준 (Acceptance Criteria)

- [ ] 50문항·가중치·백분율·`likelyMDD`가 코드에서 완전히 제거된다.
- [ ] PHQ-9 9문항, GAD-7 7문항, ASQ 4+1문항이 검증된 채점 규칙으로 계산된다.
- [ ] 현재 안전 확인에서 급성 위험 시 **결과 화면 없이** crisis 화면으로 이동한다.
- [ ] ASQ Q5 양성 시 결과 화면이 렌더되지 않는다(테스트로 고정).
- [ ] 결과는 척도별 점수/밴드와 다음 행동을 보여주며, 진단으로 읽히지 않는다.
- [ ] 109/119/112 및 1577-0199/1388/정신건강복지센터가 결과·위기 화면에 있다.
- [ ] 모든 문구에 "선별이며 의학적 진단이 아니다"가 포함된다.
- [ ] `node --test`와 `node bin/validate-instruments.js`가 통과한다.
- [ ] README에 출처·한계·비공식 번역 고지·응급 안내가 있다.
