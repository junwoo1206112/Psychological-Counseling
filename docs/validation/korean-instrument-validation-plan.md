# 한국어 선별도구 타당화 계획 (PHQ-9 · PHQ-A · GAD-7 · ASQ)

> 상태: **계획 수립 완료, 미수행**
> 적용 범위: 이 앱의 한국어 문항은 현재 “이해 보조용 비공식 번역”이며, 채점은 영문 원문 기준입니다.
> 목적: 상업·임상 배포 전에 한국어 문항의 의미 동등성과 측정학적 타당성을 확보합니다.

## 1. 현재 상태와 결론

| 항목 | 현재 | 목표 |
|---|---|---|
| PHQ-9/GAD-7/PHQ-A 문항 | 한국어 번역 + 영문 원문 병기, 채점 영문 기준 | 한국어판 타당화 완료 후 한국어 채점 |
| ASQ | NIMH 공식 한국어 문항 | 공식판 유지, 한국어 타당화 근거 확인 |
| 기능손상 문항 | 비채점 triage 플래그 | 한국어 표현의 인지면담 검토 |
| 임상 사용 | 불가 | IRB·자문·타당화 완료 후 |
| 상업 사용 | 불가 | 법무·규제 게이트 통과 후 |

**결정: 문항을 새로 만들지 않는다.** 검증된 영문 원문을 유지하고, 한국어 번역의 타당화만 수행한다.

## 2. 설계

### 2.1 설계 유형

- 횡단적 타당화 연구(Cross-sectional validation).
- 필요 시 임상군 대조를 포함한 2군 설계(지역사회 표본 + 임상 표본).
- 가능하면 2주 후 재검사(test–retest) 하위 표본 포함.

### 2.2 표본

| 대상 | 목표 n | 근거 |
|---|---:|---|
| 성인 지역사회(PHQ-9/GAD-7) | 300 | 문항 수 대비 5~10배, 요인분석 안정성 |
| 청소년(PHQ-A) | 200 | 12~18세, 보호자 동의 |
| 임상 대조군 | 100 | 전문가 면담 기준 진단 확인 |
| 인지면담 | 15~20 | 문항 이해·문화 적합성 |
| 재검사 하위표본 | 50 | 2주 간격 |

표본은 성별·연령·교육수준·지역을 층화해 모집합니다. 편의표본만 사용할 경우 한계를 명시합니다.

### 2.3 기준 표준

- PHQ-9/GAD-7: 구조화된 임상 면담(예: MINI, SCID) 또는 훈련된 임상가 평가.
- PHQ-A: 청소년 정신건강 전문가 면담 + 보호자 보고(가능한 경우).
- ASQ: 자살사고·시도에 대한 임상 면담 + 추적 정보.

기준 표준 평가자는 한국어 문항 점수를 보지 않도록 맹검 처리합니다.

## 3. 번역·문화 적응 절차

1. **독립 순번역 2인**: 임상 경험과 한국어/영어 능숙도를 갖춘 번역자 2인이 독립 번역.
2. **조정 회의**: 불일치 항목을 합의로 조정, 직역·의역·문화 표현 기록.
3. **역번역 1~2인**: 한국어판을 영어로 역번역, 원문과 의미 차이 확인.
4. **전문가 위원회**: 임상심리사, 정신과 전문의, 번역가, 청소년 담당자 포함. 의미 동등성·문화 적합성·문해력 검토.
5. **인지면담**: 15~20명에게 “이 문항이 무엇을 묻는지 자신의 말로 설명” 요청. 오해·불편·민감 표현 기록.
6. **파일럿**: 30~50명에게 실시해 응답 분포·바닥/천장 효과·소요시간·이해도 확인.
7. **최종 동결**: 문항 텍스트와 `contentHash`를 고정하고 버전을 부여합니다.

## 4. 분석

### 4.1 신뢰도

- 내적 일관성: Cronbach’s α, McDonald’s ω (≥0.70 허용, ≥0.80 양호).
- 재검사 신뢰도: 2주 간격 ICC (≥0.70 목표).
- 문항-총점 상관, 문항 제거 시 α 변화.

### 4.2 타당도

- 내용타당도: 전문가 위원회 + 인지면담.
- 구성타당도: 확인적 요인분석(CFA), 단일 요인 모형 적합도(CFI ≥0.90, RMSEA ≤0.08).
- 수렴·변별타당도: 우울-불안 상관, 기능손상·삶의 질과의 관계.
- 준거타당도: ROC/AUC, 절단점별 민감도·특이도·PPV·NPV.
- 측정불변성: 성별·연령대·교육수준 간 configural/metric/scalar invariance 검토.

### 4.3 절단점 정책

- 기존 영문 기준(0–4/5–9/10–14/15–19/20–27 등)을 참조하되, 한국어 표본의 ROC 결과와 PPV를 함께 보고합니다.
- 절단점을 변경할 경우 앱의 밴드·라우팅·문구를 새 버전으로 동결하고 회귀 테스트합니다.
- **검증 전에는 “한국어판 타당화 완료”라고 표시하지 않습니다.**

## 5. 윤리·데이터 보호

- IRB 심의 또는 면제 확인(기관·국가 규정에 따름).
- 서면/전자 동의, 민감정보 별도 동의, 만 14세 미만 법정대리인 동의.
- 이름·연락처 등 직접 식별자는 분석 데이터와 분리하고, 연구 ID만 사용.
- 원자료 암호화, 접근 권한 최소화, 보관 기간·파기 절차 명시.
- 자살 위험 응답에 대한 즉시 대응 프로토콜(109/119/112, 임상 감독자 연락).
- 참여 철회·데이터 삭제 절차 안내.

## 6. 일정과 산출물

| 단계 | 산출물 | 예상 |
|---|---|---|
| 1. 번역·역번역 | 번역 대조표, 불일치 기록 | 2~3주 |
| 2. 전문가 위원회 | 의미 동등성 검토서 | 1~2주 |
| 3. 인지면담 | 문항별 이해도 보고서 | 3~4주 |
| 4. 파일럿 | 파일럿 결과 보고서 | 4주 |
| 5. 본조사 | 데이터셋, 분석 코드 | 8~12주 |
| 6. 분석·보고 | 타당화 보고서, 절단점 권고 | 4주 |
| 7. 앱 반영 | 버전·해시·회귀 테스트 | 1~2주 |

## 7. 앱 반영 게이트

실제 연구·승인 과정의 최소 증빙은 [한국어 타당화 증빙 레지스트리](../operations/korean-validation-evidence.md)에 비식별 식별자로 기록합니다. 이 계획의 체크박스나 `translationStatus`만 수정해서는 릴리스 준비도 게이트를 통과할 수 없습니다.

- [ ] 번역 대조표·역번역·전문가 위원회 기록 완료
- [ ] 인지면담 15~20명 완료
- [ ] 파일럿 30~50명 완료
- [ ] 본조사 목표 표본 확보
- [ ] 신뢰도·CFA·ROC 분석 완료
- [ ] 절단점·PPV/NPV 보고
- [ ] IRB/동의/데이터 보호 문서 완료
- [ ] `INSTRUMENT_META`의 `translationStatus`를 `validated-ko`로 변경
- [ ] `translationVersion`·`translationHash` 갱신
- [ ] `npm.cmd run validate`, `npm.cmd test`, `npm.cmd run a11y`, `npm.cmd run build:web` 통과

`npm.cmd run validation:evidence:check`은 연구 증빙의 형식·단계·현재 문항 지문 해시만 검사합니다. 연구의 과학적 적절성이나 IRB·임상·법무 승인 사실은 독립 검토자가 판단합니다.
